# What is Automated Hell?
Automated Hell is a mod to the MTG Forge engine with cards from the Hell's Cube!

## What is Forge?
There is an open source game called [Forge](https://github.com/Card-Forge/forge), it's an automated MtG Simulator. 
It got a bit famous because of the Adventure mode which kinda plays like the old Shandalar games. With bosses, dungeons and stuff.

It also supports custom cards, so...why not start importing cards from Hell's cube to it?

## What is Hell's Cube?
Hell's Cube is a collection of humorous and insane cards made by a bunch the Magic Community! 
[Learn more about it on their subreddit!](https://www.reddit.com/r/HellsCube/comments/1v1wjzi/hellscube_quickstart_guide_and_faq/)

## Just let me play it, already!
Ok, ok, geez!

On Windows:
0. Download and install [Forge](https://github.com/Card-Forge/forge)
1. Download the repository in .zip form
2. Extract files on the /custom folder to %appdata%/Forge/custom
3. Extract files on the /pics folder to %localappdata%/Forge/Cache/pics
4. Enjoy!

## What do I do with all those goofy ahh cards?
For now, create constructed decks and play with the AI! They can also appear on the Adventure mode! They were not tested on Multiplayer yet, but they should work there too.
